# 视频嗅探播放器

一个基于 Chrome Manifest V3 的浏览器扩展：自动嗅探当前网页中的视频 / 音频资源，并用简洁的黑白风格 H5 播放器单独播放，支持全屏、倍速播放与画中画。

## 功能特性

- **双重嗅探**
  - 网络嗅探：通过观察型 `webRequest` 监听网络请求，捕获 MP4、WebM、M3U8（HLS）、MPD（DASH）等媒体地址。
  - DOM 扫描：解析页面中的 `<video>` / `<audio>` / `<source>`、懒加载属性、`og:video` 等 meta 标签以及 `link[rel=preload]`，并通过 `MutationObserver` 动态补充新出现的资源。
- **资源列表**：弹窗展示当前标签页捕获到的所有媒体资源，标注类型（MP4 / WebM / HLS / DASH / 音频等），支持单个播放、复制地址与「播放全部」。
- **独立 H5 播放器**：黑白极简风格，自带播放列表，支持：
  - 播放 / 暂停、进度拖拽、音量与静音
  - 无级倍速调节（0.1× – 16×，带常用预设）、记忆上次倍速
  - 全屏、画中画
  - 键盘快捷键：空格播放/暂停、`M` 静音、`F` 全屏、方向键 ±5 秒
- **悬浮入口**：内容脚本用 Shadow DOM 在页面右下角渲染悬浮按钮（样式完全隔离，不污染页面），显示可播放资源数量，点击即可打开播放器。
- **状态维护**：按标签页隔离资源列表，页面跳转或标签关闭时自动清理；扩展图标角标显示当前页面可播放资源数。

## 安装与使用

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 打开右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目目录。
4. 打开任意含视频的网页，点击工具栏中的扩展图标，即可在弹窗中查看嗅探到的资源并播放。

> 也可以使用打包好的 `video-sniffing-player.zip`（在浏览器中解压后加载），该文件不会提交到 Git。

## 目录结构

```
video-sniffing-player/
├── manifest.json        # 扩展清单（MV3）
├── background.js        # 后台 Service Worker：网络嗅探、资源汇总、消息路由
├── content.js           # 内容脚本：DOM 扫描、上报、Shadow DOM 悬浮入口
├── popup.html/css/js    # 点击扩展图标后的资源列表弹窗
├── player.html/css/js   # 独立 H5 播放器页面（播放列表、倍速、全屏、画中画）
└── icons/               # 扩展图标（16/32/48/128）
```

## 工作原理

1. `background.js` 使用观察型 `chrome.webRequest`（仅监听、不拦截，符合 MV3 规范）收集媒体请求，并接收内容脚本上报的 DOM 资源，按标签页存入 `chrome.storage.session`。
2. `popup.js` 点击「刷新」时请求内容脚本重新扫描，并从后台拉取资源列表进行展示。
3. 选择播放后，资源队列写入 `chrome.storage.local`，并通过 `chrome.tabs.create` 打开 `player.html`，由播放器按队列播放。

## 说明与限制

- 需 Chrome 116 及以上版本。
- 受浏览器原生能力限制，HLS（`.m3u8`）/ DASH（`.mpd`）能否播放取决于站点与原始流的支持情况，扩展不会转封装。
- 受同源 / 防盗链等因素影响，部分资源地址可能无法在播放器中直接播放。
- `blob:` 类型的媒体流标记为「不可播放」（无法跨上下文直接播放）。
- 权限说明：`storage`（存取资源列表与配置）、`tabs`（读取当前标签页信息）、`scripting`（必要时注入扫描脚本）、`webRequest`（监听网络请求）、`<all_urls>`（在所有页面嗅探）。

## 隐私

扩展仅在本地浏览器中处理数据，不上传、不收集任何用户信息。
